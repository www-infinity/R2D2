## 📞 Signal Number Format

Every device gets a unique **8-block emoji number** derived from its browser fingerprint:

```
😎🟦👌🟥🎷🟨♣️⬜   ← standard 8-block (new user)
🛸🟦🌻🟨💃⬜🐴🟩   ← example profile block
```

Numbers grow longer as more users join the network.
Each block maps to a unique audio frequency (220 Hz – 1976 Hz).

## 🌐 Deploy

### GitHub Pages (automatic)
The `deploy.yml` workflow deploys to GitHub Pages on every push to `main`.

**Enable Pages in your repo:**
1. Settings → Pages → Source → **GitHub Actions**
2. Push to `main` — the site goes live automatically.

### Cloudflare Pages (optional)
1. Add secrets `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID`
2. Uncomment the Cloudflare step in `.github/workflows/deploy.yml`
3. Or connect via Cloudflare Dashboard → Pages → Connect to Git → select this repo
